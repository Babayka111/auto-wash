# АкваПлюс — личный кабинет автомойки

Готовый учебный веб-проект: HTML/CSS/JavaScript, Node.js/Express, PostgreSQL 16.

## Функции

- Главная, каталог услуг, регистрация/вход, онлайн-запись, личный кабинет, мои записи, история, админ-панель.
- Три роли: гость, клиент, администратор.
- Добавление/изменение автомобилей, изменение профиля, запись на несколько услуг, расчет цены и длительности.
- Просмотр свободного времени по постам обслуживания; транзакционная защита от двойной записи.
- История заказов, отмена предстоящей записи, изменение статусов администратором.
- Админ-панель: заказы, услуги, список клиентов, посты мойки и блокировки расписания.
- 11 связанных таблиц БД (3НФ), хеширование паролей bcrypt, хеши серверных сессий SHA-256.
- Защита от SQL-инъекций параметризованными запросами, от XSS — экранированием и CSP, проверка ролей на сервере, страницы 404/500.

## Запуск на Windows / Linux

Нужны Node.js 20+ и PostgreSQL 16+. Самый простой способ поднять БД — Docker Desktop.

1. Распакуйте ZIP в папку **без кириллицы** (необязательно, но удобнее для Windows).
2. Откройте терминал в корне проекта.
3. Запустите PostgreSQL:
   ```bash
   docker compose up -d
   ```
   Если Docker не установлен, создайте вручную в PostgreSQL базу `autowash` и пользователя `autowash` с паролем `autowash`, либо укажите свои реквизиты в `.env`.
4. Скопируйте `.env.example` в `.env`. В Windows: `copy .env.example .env`.
5. В `.env` замените `ADMIN_PASSWORD` на **свой надежный пароль**, при желании измените `ADMIN_EMAIL`.
6. Выполните последовательно:
   ```bash
   npm install
   npm run db:init
   npm run db:seed
   npm start
   ```
7. Откройте **http://localhost:3000**.
8. Для администратора войдите под `ADMIN_EMAIL` и `ADMIN_PASSWORD` из вашего `.env`; обычного пользователя зарегистрируйте через сайт.

> `npm run db:seed` создает администратора **только если почты еще нет**. Не изменяет существующие роли/пароли, чтобы исключить случайное повышение привилегий.

## Работа без Docker

В `.env` укажите `DATABASE_URL=postgresql://ИМЯ:ПАРОЛЬ@localhost:5432/ИМЯ_БД`. Предварительно создайте базу и пользователя в локальном PostgreSQL. После этого выполните `npm run db:init`, `npm run db:seed`, `npm start`.

## Структура

- `public/*.html` — отдельные HTML-страницы (без смешивания HTML и JS).
- `public/css/style.css` — адаптивные стили.
- `public/js/*.js` — логика страниц, обращения к API.
- `server/index.js` — сервер, REST API, права доступа.
- `db/schema.sql` — схема БД и стартовые услуги.
- `db/init.js` — создание таблиц; `db/seed.js` — первый администратор.
- `docker-compose.yml` — PostgreSQL 16.

## Обратите внимание

- Часы приема: ежедневно с 09:00 до 20:00; доступные интервалы с шагом 30 минут.
- Запись на ближайшее время возможна не раньше чем через 30 минут; платежный шлюз не предусмотрен, оплата при визите.
- Исторические цены услуг сохраняются в `order_services`.
- Изменение статусов доступно только администратору.
- Заявки клиента нельзя увидеть через API другого клиента.
- Для **продакшн-развертывания** обязательны HTTPS, корректный `APP_ORIGIN`, отдельные секреты/пароли БД, резервное копирование, управление логами, настройка часового пояса сервера и дополнительное тестирование.
- Шрифты загружаются из Google Fonts при наличии интернета; при отсутствии используется локальный Arial.

## Проверка

`npm run check` — синтаксис основных JS-файлов. Для полноценной проверки нужен запущенный PostgreSQL и установленные зависимости.
